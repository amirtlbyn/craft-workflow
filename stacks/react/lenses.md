## Component Lens

- Props are typed and component responsibilities stay narrow.
- Hooks follow the Rules of Hooks and have complete dependency arrays.
- Loading, error, empty, and success states are explicit.
- Expensive work is measured before memoization is introduced.

## Accessibility Lens

- Interactive elements use semantic HTML and support keyboard input.
- Labels, focus management, live updates, and contrast meet WCAG AA.
- Automated checks use axe or an equivalent browser-level tool.
